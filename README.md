# **🎯 Key Performance Indicators (KPIs)**

👥 Total Users – Total number of users in the dataset

📢 Total Followers – Combined followers across all users

➕ Total Following – Total accounts followed by users

📝 Posts per Week – Average weekly content creation activity

🌍 Users by Country – Geographic distribution of users

👨‍👩‍👧‍👦 Users by Gender – Demographic breakdown

⭐ Influencer Status Analysis – Influencers vs Non-Influencers

📱 Primary Platform Analysis – Most preferred social media platforms

⏰ Peak Usage Time – Most active periods of the day

📈 Daily Usage Hours – Average time spent on social media

🔄 Shares per Day – User content-sharing activity

⚡ Scroll Speed Analysis – User browsing behavior

🎯 Primary Purpose Analysis – Main reasons for social media usage

---

# **📊 Insights & Expected Outcomes**

🌍 Pakistan, India, and the USA have the highest number of users in the dataset.

👩 Female users slightly outnumber male users, showing balanced platform participation.

📱 Facebook, Instagram, TikTok, and LinkedIn remain among the most popular platforms.

⭐ The majority of users are non-influencers, while influencers represent a smaller but significant segment.

⏰ Evening and night hours show the highest user activity levels.

📈 Users spend several hours daily on social media, indicating strong engagement.

🔄 Content sharing behavior varies significantly across countries.

🎯 Entertainment, business, learning, networking, and socializing are among the primary reasons for platform usage.

---

# **📚 Data Story**

The dashboard reveals how social media has become an essential part of daily life across different countries and demographics.

### Key findings include:

Users spend significant time engaging with social media platforms daily.
Peak activity occurs during evening and nighttime hours.
Entertainment and networking are major drivers of engagement.
Platform preference differs across regions and user groups.
Influencers contribute heavily to content creation and audience engagement.
Geographic analysis highlights regions with stronger social media adoption.

👉 Overall, user engagement is strongly influenced by:

Demographics,
Platform preference,
Daily usage habits,
Content-sharing behavior,
Time of activity,
Geographic location,
